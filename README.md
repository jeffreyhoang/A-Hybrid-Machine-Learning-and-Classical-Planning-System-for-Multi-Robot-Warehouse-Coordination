# A Hybrid Machine-Learning and Classical-Planning System for Multi-Robot Warehouse Coordination

## Abstract
AutonomousAutonomous warehouses rely on multiple mobile robots to transport packages efficiently while avoiding collisions, congestion, and deadlocks. This project proposes a hybrid coordination system that combines classical multi-agent path planning with a learned conflict-resolution policy. Classical methods such as A* and prioritized planning will generate and verify safe robot routes, while a machine-learning model will predict which robot should move first when two or more planned routes conflict. The system will be developed and evaluated in a simulated warehouse using procedurally generated layouts, robot tasks, obstacles, and dynamic task arrivals. Performance will be compared against classifcal planning baselines using collision rate, deadlock frequency, makespan, delivery time, path length, task-completion rate, and computational cost. The goal is to determine whether a learned local coordination policy can improve warehouse efficiency while preserving the safety advantages of classical planning.
