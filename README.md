# A Hybrid Machine-Learning and Classical-Planning System for Multi-Robot Warehouse Coordination
> A hybrid coordination system combining classical multi-agent path planning with learned conflict-resolution policies for autonomous warehouse management


## Team Members
- Jeffrey Hoang


## Abstract
Autonomous warehouses rely on multiple mobile robots to transport packages efficiently while avoiding collisions, congestion, and deadlocks. This project proposes a hybrid coordination system that combines classical multi-agent path planning with a learned conflict-resolution policy. Classical methods such as A* and prioritized planning will generate and verify safe robot routes, while a machine-learning model will predict which robot should move first when two or more planned routes conflict. The system will be developed and evaluated in a simulated warehouse using procedurally generated layouts, robot tasks, obstacles, and dynamic task arrivals. Performance will be compared against simple priority rule, classical prioritized planning, and classical planner with replanning baselines using safety, efficiency, and classical machine learning metrics. The goal is to determine whether a learned conflict-resolution policy can improve warehouse efficiency while preserving the safety advantages of classical planning.
