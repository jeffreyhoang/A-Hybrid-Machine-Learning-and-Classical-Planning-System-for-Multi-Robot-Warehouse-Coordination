# Literature Review


## Improving Learnt Local MAPF Policies with Heuristic Search

### Overall Objective
The paper investigates how to improve machine learning policies for multi-agent path finding (MAPF). Existing learned policies typically predict only each agent’s next action, which can result in collisions, deadlocks, and poor scalability. The authors aim to combine these local machine learning predictions with heuristic search so that the system can make safer and more effective long-horizon decisions. 

### Key Innovation
The main innovation is using heuristic search to process and improve the action predictions generated by a learned policy. The paper introduces:
- CS-PIBT, a “smart” collision shield that uses priorities, backtracking, and the model’s full action-probability distribution to resolve conflicts.
- A method for integrating learned policies with LaCAM, allowing local machine learning predictions to guide full-horizon search.
- A strategy for combining learned action probabilities with heuristic values to improve action selection and solution cost.

The experiments show that these hybrid methods substantially improve the success rate and scalability of learned MAPF policies, especially in highly congested environments. However, strong classical methods can still outperform the learned methods in standard 2D environments. 

### Main Limitation
The main limitation is that the evaluation focuses on simplified, known 2D grid environments with discrete movements, static obstacles, and predetermined start-goal pairs. These conditions do not represent many challenges of a real robotic system, such as continuous motion, vehicle orientation, acceleration, sensor uncertainty, changing goals, or task arrivals. In addition, the paper finds that when a highly accurate heuristic is available, the classical LaCAM planner outperforms the learned policies. The learned models are more advantageous when the heuristic is imperfect, unavailable, or computationally expensive.
